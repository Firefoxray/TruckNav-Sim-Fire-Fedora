# Thanks & Acknowledgements

TruckNav Linux exists because of the work that came before it.

## TruckNav

A huge thank you to **Rares Muntean** and the original [TruckNav-Sim](https://github.com/Rares-Muntean/TruckNav-Sim) project for the application, navigation UI, routing work, telemetry integration, and overall foundation this fork is built on.

If you want to support the original TruckNav project, see the upstream repository and its project links.

## truckermudgeon/maps

Special thanks to [@truckermudgeon](https://github.com/truckermudgeon) for the [maps](https://github.com/truckermudgeon/maps) project.

Its SCS map parser/generator became the foundation for the maintainable ATS map pipeline in this fork and made it possible to rebuild current routing and visual map data from installed game files.

## RenCloud / SCS telemetry

Thanks to [@RenCloud](https://github.com/RenCloud) for [scs-sdk-plugin](https://github.com/RenCloud/scs-sdk-plugin) and the telemetry work that underpins communication with the SCS games.

## Linux work

Thanks to the Linux community work around TruckNav, including [Jeroen van Straten / TruckTel](https://github.com/jvanstraten/TruckTel), which was referenced by the upstream project as Linux integration work.

## Development assistance

OpenAI / ChatGPT assisted with implementation, debugging, documentation, and the Linux/map pipeline work in this fork.

## SCS Software

American Truck Simulator and Euro Truck Simulator 2 are created by **SCS Software**. This fork is an independent project and is not affiliated with or endorsed by SCS Software.
